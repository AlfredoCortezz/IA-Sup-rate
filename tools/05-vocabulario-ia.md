# 📖 Vocabulario de la IA — el glosario en cristiano

Cuando leas una palabra rara, búscala aquí. Está ordenado por las semanas.

## Semana 1 — Conceptos base

| Término | En cristiano |
|---------|--------------|
| **IA** | Programas que aprenden de ejemplos para predecir o decidir. NO piensa, NO siente, NO tiene consciencia. |
| **IA simbólica** | La vieja escuela: reglas escritas a mano por humanos ("SI llueve ENTONCES lleva paraguas"). |
| **IA conexionista** | La escuela moderna: la máquina aprende patrones desde millones de ejemplos (redes neuronales). |
| **Modelo** | El "cerebro" ya entrenado; la máquina de predicciones. |
| **Entrenamiento** | El proceso donde el modelo ve ejemplos y ajusta sus conexiones. |
| **Teachable Machine** | Herramienta de Google para entrenar un mini-modelo con fotos/sonidos SIN escribir código. |

## Semana 2 — IA generativa

| Término | En cristiano |
|---------|--------------|
| **Token** | La unidad mínima de texto que lee una IA. No es una palabra completa: "casa" puede ser 1 token, pero "casas" 2. |
| **Embedding** | Convertir palabras en listas de números (vectores) para que el modelo "entienda" relaciones (rey - hombre + mujer ≈ reina). |
| **Atención** | El mecanismo que decide qué palabras importan más en la frase (¿a qué se refiere el "él" en el párrafo?). |
| **Prompt** | La instrucción que le escribes a la IA. Un buen prompt = una buena respuesta. |
| **Alucinación** | Cuando la IA inventa datos falsos pero confiados. NO "miente" a propósito: solo está completando texto. |
| **Sesgo (bias)** | Cuando un modelo hereda prejuicios de los datos mal balanceados con que se entrenó. |
| **Ingeniería de prompts** | El arte de escribir instrucciones claras con rol, contexto y restricciones. |

## Semanas 3–8 — Machine Learning

| Término | En cristiano |
|---------|--------------|
| **ML (aprendizaje automático)** | Programas que mejoran su precisión con datos, sin ser programados regla por regla. |
| **Dato etiquetado** | Un ejemplo con su respuesta correcta (ej. película + cuánto la gustó). |
| **Datos de entrenamiento / prueba** | Partes del set: una para aprender y otra para COMPROBAR que no memorizó. |
| **Overfitting (sobreajuste)** | El modelo "memoriza" los ejemplos de entrenamiento y falla con datos nuevos (le faltó repasar con pruebas). |
| **Underfitting** | El modelo es tan simple que no capta el patrón. |
| **Regresión** | Predecir un NÚMERO (calificación, precio, temperatura). |
| **Clasificación** | Predecir una CATEGORÍA (sobrevivió/murió, spam/no spam). |
| **Feature (característica)** | Cada columna que describe el dato (edad, horas de estudio…). |
| **Hiperparámetro** | Las "perillas" del modelo que tú ajustas (nº de vecinos k, profundidad del árbol…). |

## Semanas 9–10 — Web

| Término | En cristiano |
|---------|--------------|
| **Componente** | Pieza de código reutilizable (botón, tarjeta, página) que renderiza HTML. |
| **API / endpoint** | Una "ventanilla" de internet que devuelve datos (normalmente JSON) a quien le pregunte. |
| **JSON** | Formato de datos: `{ "nombre": "Ana", "edad": 17 }`. La forma en que las apps hablan entre sí. |
| **Frontend** | Lo que ve el usuario (navegador). |
| **Backend** | Lo que vive en el servidor: base de datos, lógica, APIs. |
| **Deploy** | Subir tu app a internet para que el mundo la use. |
